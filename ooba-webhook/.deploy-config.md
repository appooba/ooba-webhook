# Deploy Configuration — OOBA Webhook

## Remotes
- `github` → GitHub (appooba/ooba-webhook) — **PRINCIPAL**, trigga auto-deploy da Vercel
- `base44` → Base44 internal repo (backup)
- `all` → Pusha para AMBOS simultaneamente

## Como fazer deploy
```bash
# Após editar webhook.js (ou outros arquivos):
git add -A
git commit -m "descrição da mudança"
git push all main    # ← pusha pro GitHub E Base44 ao mesmo tempo
```

## Fluxo automático
1. Push pro GitHub → Vercel detecta → build automático → deploy em ~20s
2. Push pro Base44 → backup interno

## Importante
- **SEMPRE use `git push all main`** para garantir que o deploy aconteça
- Nunca use apenas `git push origin main` (origin não existe mais)
- O GitHub é o que trigga a Vercel — sem push no GitHub, não há deploy
